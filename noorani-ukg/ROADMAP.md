# Roadmap — only if the 5-day test is positive

**Define "positive" before you start** (from the Founder view + export): Days 1–5 each finished in ≤45 min with ≤25 min screen; ≥4 of 5 days completed without you forcing it; offline activities actually done (not just tapped); and Aisha asks for it on at least 2 days. If any of these fail, fix the loop — not the feature list.

## Next version (in this order)

1. **Make the religious layer trustworthy** — alim signs off `CONTENT_REVIEW.md`; Tanzil text fetched and checked against a mushaf; verified human recordings for Bismillah, the duas and Al-Ikhlas (fill `audioUrl`). This is the trust moat — no parent will forgive one error here.
2. **Bengali teacher review + native voice** — proofread all Bengali; record a warm human voice for child prompts instead of relying on device TTS (most budget phones have no Bengali voice).
3. **Test with 5–10 real families** (not yourself), on their phones, for one week. Measure the same Founder-view metrics plus a 2-question parent check-in per day.
4. **Weeks 2–4 of content** using the same schema, plus a lightweight authoring sheet so a teacher can write lessons without code.
5. **Installable PWA + offline cache**, and **cloud backup / sync** (only now does a backend become justified) so progress survives phone changes.
6. **Real teacher loop** — a human ustadha reviewing weekly observations/photos. Decide whether this is the paid layer.

## Explicitly not next
Gamified streaks, AI chat with the child, leaderboards, more subjects, school-recognition claims.
